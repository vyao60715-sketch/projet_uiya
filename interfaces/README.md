# Interfaces (maquettes) – Patrimoine UIYA

Maquettes des écrans de l'application web et de l'application mobile.

- `index.html` : page d'accueil qui affiche tous les écrans ; ouvrir dans un navigateur.
- `images/` : une capture PNG par écran (numérotées de 01 à 18).
- `html/` : chaque écran en page HTML autonome ; les liens du menu passent d'un écran à l'autre.

| --- | --- | --- | --- |

| 02 | Tableau de bord | Web | Gestionnaire |
| 03 | Espace responsable de service | Web | Responsable |
| 04 | Liste des biens | Web | Gestionnaire |
| 05 | Enregistrer un bien (QR attribué automatiquement) | Web | Gestionnaire |
| 06 | Fiche d'un bien + code QR + historique | Web | Gestionnaire |
| 07 | Demandes à valider | Web | Gestionnaire |
| 08 | Campagne d'inventaire et écarts | Web | Gestionnaire |
| 09 | Maintenance et garanties | Web | Gestionnaire |
| 10 | Rapports (PDF / Excel) | Web | Gestionnaire, administrateur |
| 11 | Administration des comptes | Web | Administrateur |
| 12 | Connexion | Mobile | Tous |
| 13 | Accueil agent | Mobile | Agent d'inventaire |

| 15 | Fiche après scan | Mobile | Tous |
